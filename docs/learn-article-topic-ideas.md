# Learn About ILIT article topic ideas

Backlog of future `/learn-about-ilit/[slug]` cluster page topics — the
"big broad topics" tier (see `docs/blog-content-guide.md` for how this
differs from Blog, which handles narrower topics). Add to this list as
ideas come up rather than losing them.

- **Allergy-induced asthma / allergy-related asthma** (2026-09-23) —
  target keywords "allergy induced asthma" and "allergy related asthma."
  Reference: premierallergyohio.com's ILIT service page frames this as
  "for patients with asthma triggered by allergens, [ILIT] may improve
  breathing and reduce flare-ups" — appropriately hedged (not a cure
  claim), good model for how to handle this topic without overclaiming.
  Companion FAQ ("Can ILIT help with my asthma?") already added to the
  Learn About ILIT page's evergreen FAQ section as of this date; this
  article would go deeper on the same claim.

- **ILIT safety and FDA review status** (2026-09-23) — deeper dive on
  ILIT's safety profile and its FDA approval status (not yet approved,
  same situation as SLIT/allergy drops). The Learn page's "Is ILIT Safe?"
  section already covers this at a summary level, including that ILIT
  began clinical trials in the 2000s (source: Senti et al. 2008 RCT,
  PNAS, PMID 19001265, ClinicalTrials.gov NCT00470457) but hasn't yet
  been reviewed for FDA approval. Reference for a deeper article:
  health.osu.edu/health/general-health/ilit-allergy-shots (same source
  already used for the ultrasound-guidance and other-treatment-options
  content on the Learn page).
