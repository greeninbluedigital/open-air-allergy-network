# Article drafting queue

The daily drafting run (`docs/content-pipeline.md`) takes the first `next`
item, drafts it, and marks it `drafted YYYY-MM-DD`. The owner and the main
session reorder, add or remove items. Details for each topic are in
`docs/content-ideas.md`. Status values: `next`, `drafted <date>`,
`published <date>`, `needs code` (built in the main session, skip), `hold`.

**Hero image:** paste the image URL in the last column of a row any time
before or after it's drafted. The drafting run copies it to the draft's
"Feature image" line. The main session checks the photo and its alt text
before publishing.

**Section: always Blog (owner, 2026-10-20).** Every new article publishes to
`/blog/`. The Section column below is historical. An item appears on the
Learn About ILIT page only when the owner marks it "Learn page: Yes" below
(birch and grass were agreed 2026-10-20); the draft then adds the tag
`Allergy Treatment Guides` to its Tags line. Never set that yourself, and
never on regional or city articles.

**Published drafts** move to `published/` once the article is live, so this
folder only holds drafts still waiting on review. Their Draft file entries
below point there.

**Follow-up when publishing `traveling-for-ilit` (owner's reminder):** check
that its links switched on (search page out-of-area line, "Why travel for
ILIT?" on state pages and Providers by State), and bring up linking city
pages to neighboring states.

**Order (owner, 2026-10-24):** a weekly mix with at least one or two
